# Aethermoor

Aethermoor es un videojuego desarrollado como proyecto académico utilizando Godot Engine.

El proyecto fue realizado de manera colaborativa, aplicando conceptos de programación, diseño de mecánicas, organización de escenas y control de versiones mediante Git y GitHub.

##  Tecnologías

- Godot Engine 4.6
- GDScript
- Git
- GitHub

##  Características

- Menú principal
- Sistema de movimiento del jugador
- Escenarios interactivos
- Sistema de audio
- Mecánicas de juego desarrolladas mediante scripts
- Organización mediante escenas y nodos de Godot

##  Trabajo en equipo

El proyecto fue realizado de forma colaborativa como parte de nuestra formación universitaria.

Mi participación incluyó tareas relacionadas con:
- Desarrollo e implementación de funcionalidades.
- Integración de escenas y scripts.
- Resolución de errores.
- Control de versiones mediante Git y GitHub.

##  Ejecución

1. Instalar Godot Engine 4.6.
2. Clonar el repositorio:

git clone https://github.com/NicoBas1921/Aethermoor-Game.git

3. Importar `project.godot` desde Godot.
4. Ejecutar el proyecto.
